# Slice 7: Git — "See Repos"

**type:** epic  
**status:** planned  
**verify:** `git clone ssh://localhost:2222/myrepo`

## Purpose

Built-in Git server with SSH transport, repository management, and LFS support. Enables BigBase to function as a complete Git hosting platform.

## Scope

- SSH server on port `2222` (configurable)
- `git clone`, `git push`, `git pull` over SSH
- Repository creation (`POST /api/git/repos`)
- Repository listing (`GET /api/git/repos`)
- LFS (Large File Storage) support
- Web UI file browser (admin integration)

## Design Decisions

- Use `go-git` library (pure Go) — no `git` binary dependency
- SSH key authentication — users upload public keys via admin UI
- Repos stored on disk at `data/git/`
- LFS uses storage component backend
- Authorization checks per repo (public/private)

## Implementation Plan

### API Routes

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/api/git/repos` | Yes | Create repo |
| GET | `/api/git/repos` | Yes | List repos |
| GET | `/api/git/repos/:id` | Yes | Get repo details |
| DELETE | `/api/git/repos/:id` | Yes | Delete repo |
| POST | `/api/git/keys` | Yes | Add SSH public key |
| GET | `/api/git/keys` | Yes | List SSH keys |

### Auto-migration

```sql
CREATE TABLE IF NOT EXISTS git_repos (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    owner_id INTEGER NOT NULL,
    private INTEGER NOT NULL DEFAULT 1,
    default_branch TEXT NOT NULL DEFAULT 'main',
    description TEXT DEFAULT '',
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS git_ssh_keys (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    name TEXT NOT NULL,
    public_key TEXT NOT NULL,
    fingerprint TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

## Verify

```bash
# Create repo
curl -X POST /api/git/repos \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \

# Clone
git clone ssh://git@localhost:2222/myproject
cd myproject && echo "hello" > README.md
git add . && git commit -m "init"
git push origin main
```
