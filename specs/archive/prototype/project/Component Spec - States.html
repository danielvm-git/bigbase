Component states

Every interactive component in the BigBase Console, documented across its full state range — default, hover, focus, active, disabled, loading, error, and empty. Each row lists the exact token, spacing, and transition. All values are read live from spec.css; flip dark mode or an accent theme (sidebar) to verify contrast. States shown in the tables are pinned for reference; the preview strips are fully interactive.

4.0 State coverage matrix

Every component checked against the 12 canonical states of the system. A ✓ means the state is defined in spec.css and demonstrated below; a muted · means it does not apply to that component (e.g. a Divider has no loading state, a Badge no focus). This makes the full range explicit per component — the detailed cards that follow document the tokens and transitions for each ✓.

A Actions

Buttons share one base: display:inline-flex, gap --space-3, padding --space-4 --space-8 (8/16px), radius --radius-s, --text-s / 500, border 1px solid transparent. Press nudges translateY(0.5px) — never a scale. Transition: background-color · border-color · opacity · transform @ --duration-fast (150ms) --ease-standard.

F Feedback & status

Motion is quick (150–300ms) and purposeful. Things that travel use --ease-emphasized; loading uses skeleton shimmer or a spinner. No bounces.
