Accessibility verification

BigBase targets WCAG 2.1 AA. The contrast figures below are computed from the actual token values in spec.css using the WCAG relative-luminance formula — not estimated. Every accent theme passes on both light and dark surfaces, neutral text pairs clear 4.5:1 for body text, focus is always visible, status is never color-alone, and icon-only controls carry labels.

8.3 Neutral text pairs

The grayscale roles that carry most of the UI. Primary and secondary clear AA for normal text; tertiary is reserved for large text, metadata, and disabled affordances (it is never the only carrier of essential information).

Role pairRatioUse

--fg-tertiary on surface is ~4.8:1 (light) / ~3.5:1 (dark) — it sits at the large-text threshold and is used only for de-emphasized metadata (timestamps, hints, placeholders), never body copy or the sole label of a control.

8.4 Conformance checklist

Focus visible on all interactive elements

A single --focus-ring token (3px indigo @ 18%, re-tinted per theme at 30%) renders on :focus-visible for buttons, inputs, selects, tabs, nav items, choice cards, and the theme picker. Keyboard focus is never suppressed.

Contrast ≥ 4.5:1 across all 12 themes + dark mode

Verified by computation (§8.2). Dark mode remaps --fg-accent to a lightened indigo (#807AEC) because the default sits at 2.67:1 on near-black — the remap restores 4.7:1.

Status never by color alone

Every status pairs a word + a dot or spinner + a color: Ready Building Failed. Safe for color-blind users and grayscale print.

Aria labels on icon-only buttons

Toast dismiss, copy-URL, row actions, file actions, pipeline re-run, remove-variable, and open-template buttons all carry aria-label (or title). The theme trigger uses aria-haspopup="listbox" + aria-expanded; the menu uses role="listbox" / role="option" with aria-selected.

Touch targets ≥ 44px on mobile

Buttons hold ≥36px desktop and pad to 44px on touch tiers; nav rail icons center a 44px hit area; form controls are 40px tall. Row-action .btn-sm buttons keep ≥8px (--space-4) spacing.

Reduced motion respected

Entrance animations gate on @media (prefers-reduced-motion: no-preference); the visible end-state is the base style, so reduced-motion users see content immediately with no pre-animation hidden state.

Semantic structure & labels

Form fields use <label> tied to controls; errors surface as adjacent text (--error + alert icon), not color or placeholder alone. Headings descend in order; tables use <th> headers.
