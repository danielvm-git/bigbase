The complete token reference, named exactly as in the codebase (colors_and_type.css). Spacing, color, type, radius, shadow, and motion are all CSS custom properties — components reference roles (--bg-accent), roles reference primitives (--brand-500), so a theme only has to remap primitives. 99 tokens total.

9.7 Dark-mode remap

Dark mode is a single [data-theme="dark"] block that remaps role tokens — primitives and components are untouched. The notable special case: the indigo accent text is too dark on near-black, so it lightens.

9.8 Theme switching & persistence

Accent themes are applied by setting data-accent on <html>; dark mode by data-theme. Both persist to localStorage. Because every component reads role tokens, a theme switch is instant and global with zero re-render of component CSS.

// Apply + persist accent theme (12 months, or 'default') function setAccent(month) { const root = document.documentElement; if (month && month !== 'default') root.setAttribute('data-accent', month); else root.removeAttribute('data-accent'); localStorage.setItem('bigbase-theme', month); } // Apply + persist dark mode function setDark(on) { document.documentElement.setAttribute('data-theme', on ? 'dark' : 'light'); localStorage.setItem('bigbase-dark', on ? '1' : '0'); } // Rehydrate on load (run before first paint to avoid flash) const saved = localStorage.getItem('bigbase-theme') || 'default'; const dark = localStorage.getItem('bigbase-dark') === '1'; setAccent(saved); setDark(dark);

This is exactly what the live console ships — open it, change the footer theme picker, reload, and the choice survives. The doc pages on this site use the same keys so your selection follows you across them.
