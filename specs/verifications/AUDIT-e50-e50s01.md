### Red Flags / Rationalisations Caught
One finding was identified and fixed before this report was written:

**FINDING (fixed):** `ResetTestModeForTesting` was exported from `auth.go` (production code). Any caller could invoke `auth.ResetTestModeForTesting(false)` to disable secret validation at runtime. Test infrastructure must not live in production binaries.

**Fix applied:** Removed `ResetTestModeForTesting` from `auth.go`; moved to `components/auth/export_test.go` (`package auth` in a `_test.go` file). The function is now compiled only into test binaries. `testModeOverride` and `isTestMode()` remain in `auth.go` as unexported package vars. Build and all 164 auth tests verified green after the fix.
