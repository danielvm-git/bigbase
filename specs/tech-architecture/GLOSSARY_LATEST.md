# BigBase Glossary (GLOSSARY_LATEST)

WCAG 2.2 AAA 3.1.5 mechanism: the UI contains technical terms that necessarily
read above lower-secondary level, so this glossary provides plain-language
definitions. The app footer links here so every term is reachable from a
definition mechanism (3.1.3 unusual words, 3.1.4 abbreviations).

Abbreviations that appear in the UI are also wrapped in `<abbr title="…">`
with their expansion, so both mechanisms are available.

| Term | Expansion / plain-language definition |
| --- | --- |
| ACME | Automated Certificate Management Environment — the protocol BigBase uses to obtain free TLS/SSL certificates (for example from Let's Encrypt) for deployed sites. |
| API | Application Programming Interface — the set of endpoints a program exposes for other programs to call. |
| Avg Latency | Average latency — the mean time a request takes to be answered, usually measured in milliseconds (ms). |
| BaaS | Backend-as-a-Service — a platform that provides ready-made server-side capabilities (databases, auth, storage) so you do not run your own backend. |
| Cici | BigBase's continuous integration / continuous delivery (CI/CD) workflow runner. The name repeats "CI" (continuous integration). |
| CPU | Central processing unit — the hardware that executes program instructions on a server. |
| Forge | BigBase's issue tracking and project collaboration area, named after a code forge (a platform that hosts version-controlled code and its workflows). |
| Git | A distributed version control system used to track changes to source code. |
| GitHub | A web service that hosts Git repositories and collaboration tools. |
| Goroutine | A lightweight concurrent unit of execution managed by the Go runtime. The BigBase server uses goroutines to handle many requests at once on a single machine. |
| Heap | The region of memory where a process makes dynamic allocations at runtime. "Heap MB" shows the heap memory in use by the server process, in megabytes. |
| MB / GB / KB / B | Megabyte / gigabyte / kilobyte / byte — units of digital storage or memory. |
| MCP | Model Context Protocol — an open protocol for connecting AI assistants to tools and data sources. |
| RAM | Random-access memory — the fast, working memory a computer uses while programs are running. |
| Repo | Repository — a version-controlled store of source code (usually managed with Git). |
| SQL | Structured Query Language — the standard language for querying and managing relational databases. |
| SSE | Server-Sent Events — a standard way for a server to push live updates to a web page over a single connection. |
| Uptime | The length of time the BigBase server has been running since its last restart. |
| URL | Uniform Resource Locator — the web address of a resource, for example `https://example.com`. |
| UI | User Interface — the part of the application you see and interact with. |
